# 迁移引导台（防传播版）

带口令验证 + 一次性短链接跳转的账号迁移引导页，部署在 **Vercel**。用户永远只看到你的域名和一个随机短码，看不到真实官方地址，从而防止链接被复制传播。

## 功能
- 🔒 访客需输入口令才能进入引导页
- 🎯 "前往官方迁移工具"按钮生成**一次性短码**（10 分钟内有效、用后即失效）跳转，用户地址栏只显示 你的域名/go/xxxx
- 🛑 后台管理页可改：访客口令、管理口令、总开关、公告、目标地址
- 📡 配置存于 Vercel KV，改完**立即全局生效**，无需重新部署

## 目录结构

/ (项目根)
├── vercel.json          # 路由配置
├── package.json
├── api/
│   ├── index.js         # 核心 API：status / enter / go/
│   ├── admin.js         # 后台配置 API
│   └── _store.js        # KV 存储封装
└── public/
    ├── index.html       # 访客引导页
    └── admin.html       # 后台管理页（路径由你决定，建议改名）


## 部署步骤（Vercel）

### 1. 准备 KV
Vercel 控制台进入你的项目 → **Storage** → **Create Database** → 选 **KV (Upstash)**（免费 Hobby 额度够用）→ 创建完成后会自动把连接环境变量注入项目。

### 2. 导入项目
- 方式 A（推荐）：用 vercel CLI 登录后在本目录执行 vercel 并按提示
- 方式 B：push 到 GitHub 仓库，在 Vercel 控制台 Add New Project 导入该仓库，Framework 选 **Other**

### 3. 部署
首次部署会自动安装依赖并生成函数。部署完成后你会得到形如 https://xxx.vercel.app 的网址。

## 使用
- **访客域名**：https://你的域名/
- **后台管理**：https://你的域名/admin（部署后建议立即改管理口令）

## 修改配置
直接打开后台管理页（需管理口令），即可在线修改访客口令、开关、公告等，保存后立即全局生效。

## 默认口令（部署后请务必修改！）
| 项 | 默认值 |
|---|---|
| 访客口令 | migrate2026 |
| 管理口令 | admin2026 |
| 官方地址 | https://www.runninghub.cn/wallet-migrate |

## 安全说明
- 短码为一次性、10 分钟有效期，复制给他人已失效，能有效防止链接传播
- 配置页用管理口令保护；/admin 路径建议部署后改成一个难猜的名字（重命名 public/admin.html 并同步 vercel.json 的 rewrite）
- ⚠️ 本方案防的是"普通用户复制传播"。对能逆向/暴力破解的强力攻击者，前端口令类机制始终存在局限性；如需更高安全可接入登录鉴权平台
